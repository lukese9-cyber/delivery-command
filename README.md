# Delivery Command

Role-specific project delivery operating system for Luke Jefferies' application to **Exchange for Change — Senior Project Manager, Logistics & Processing Delivery**.

## Design basis
The system is derived from the supplied job description, not from an assumed Exchange for Change internal operating model. Illustrative records are clearly separated from company facts.

## Core role controls
- Integrated logistics and processing plans covering collections, processing, partner onboarding, operational readiness and stabilisation
- Milestones, deliverables, actions, dependencies, risks, issues, budget and benefits
- External partner plan integration and supplier governance
- Cross-functional interfaces with Operations, DDaT, Finance, Procurement, Helpdesk, Legal, Comms, Regulatory, Corporate Affairs and central PMO
- Technology/data requirements, systems interfaces, testing and operational reporting
- Operations Programme Board, DDaT PMO and central PMO evidence-based governance
- Readiness, end-to-end testing, operational acceptance, cutover, handover and post-go-live stabilisation

## Interaction model
Feishu/Lark Base-inspired: one underlying record model with multiple operational views — table, Gantt, partner, dependency, RAID, decision, finance, readiness and executive exception views.

## Named partners
RLG and Wolf & Oak are included only as external delivery partners named in the supplied JD. Their detailed contractual scopes are intentionally not inferred.

## Cost model
Static HTML/CSS/JavaScript. No paid API, database or backend required. Browser-local persistence plus JSON import/export.
